## Problem

File-based publishing is easy to begin but can become unreliable when filenames, front matter,
visibility rules, and presentation expectations drift apart.

## Audience

This demonstration is intended to make the maintenance workflow understandable to a future portfolio
editor without introducing a database or a runtime administration service.

## Approach

Each record has one validated source, explicit publication flags, and deterministic derived values.
Curated compilation accepts useful long-form structures while rejecting executable or unreviewed
content behavior.

## Trade-offs

Strict schemas require deliberate edits when the content model changes. That constraint is useful
here because a static build should fail before incomplete or ambiguous records become public.
