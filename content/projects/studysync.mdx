## Overview

StudySync is an AI-powered study assistant built with Flutter, FastAPI, PostgreSQL with pgvector,
and LangChain.

## Retrieval approach

The system uses a hybrid retrieval-augmented generation pipeline that combines a learner's local
notes with cloud-hosted textbook embeddings. Offline semantic search uses ObjectBox for local vector
storage.

## Note digitization

A handwritten-note digitization pipeline uses the Microsoft Kosmos-2.5 OCR model. This description
contains only details supplied in the owner's CV; deployment, usage, and performance metrics have
not been added because they were not provided.
