## Problem

Portfolio indexes often compress every idea into an identical tile. This demonstration explores a
different constraint: preserve fast scanning while giving long-form work enough visual weight to
feel deliberate.

## Audience

The interface is framed for visitors who want to compare project themes, technologies, and maturity
without interpreting decorative signals or hidden interactions.

## Approach

The baseline document uses semantic headings, lists, links, and status text. Layout rules introduce
asymmetry only at wider viewports, so the source order remains useful on narrow screens and with
assistive technology.

## Trade-offs

A restrained system leaves less room for ornamental variation. In exchange, the content model can
replace every demonstration record without requiring a new layout or a new set of component
exceptions.
