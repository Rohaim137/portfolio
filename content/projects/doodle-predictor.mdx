## Overview

Doodle Predictor is a real-time doodle recognition web application built with Next.js,
TensorFlow.js, and Tailwind CSS.

## Machine learning

The application uses a convolutional neural network trained on the Google QuickDraw dataset to make
live predictions from a user's drawing.
